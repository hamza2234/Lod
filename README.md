# Lod

معاينة تفاعلية لنردات لودو فخمة بدون Unity.

## المحرك المستخدم في المعاينة

- **Three.js / WebGL** للمعاينة السريعة داخل المتصفح.
- مناسب لرؤية شكل النرد، اختيار الـ skin، الضغط عليه، ومشاهدة الرمي السينمائي.
- يمكن دمجه لاحقًا داخل تطبيق Kotlin عبر `WebView`، أو استخدام نفس التصميم كمرجع لبناء نسخة Godot/LibGDX داخل أندرويد.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح رابط Vite الذي يظهر في الطرفية.

## الموجود في النموذج

- نرد 3D بحواف دائرية ونقاط مضيئة.
- خمسة أشكال نرد: Royal Gold, Inferno Core, Frost Crystal, Galaxy Void, Emerald Royal.
- سوق نرد لاختيار الشكل.
- ضغط مباشر على النرد أو زر الرمي.
- حركة رمي سينمائية مع جسيمات وإضاءة ونتيجة نهائية واضحة.
