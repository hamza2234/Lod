# Luxury Ludo Dice Preview - Godot

هذا مجلد مشروع **Godot 4** حقيقي للعبة لودو Prototype، وليس صفحة HTML.

## لماذا Godot؟

- محرك ألعاب حقيقي غير Unity.
- مناسب لمشهد نرد 3D، كاميرا، إضاءة، مؤثرات، UI، وتصدير Android لاحقًا.
- يمكن استخدامه لاحقًا كتطبيق/موديول Android بجانب تطبيق Kotlin، أو إعادة بناء المنطق نفسه داخل LibGDX إذا أردت Kotlin بالكامل.

## التشغيل

1. ثبّت Godot 4.x.
2. افتح Godot.
3. اختر **Import**.
4. اختر ملف:

```text
godot-dice-preview/project.godot
```

5. اضغط **Run**.

## التحكم

- تم دمج نرد `d6.glb` حقيقي من مشروع `godot-dice-roller` المفتوح المصدر.
- في شاشة اللعب اضغط على النرد ثلاثي الأبعاد بجانب اللاعب صاحب الدور للرمي.
- إذا ظهرت أكثر من حركة قانونية في أجزاء الاختبار، اختر القطعة المضيئة.

## الموجود في المشروع

- شاشة دخول داخل المحرك.
- شاشة لوبي داخل المحرك.
- شاشة اختيار نمط اللعب مثل 4 لاعبين / 1 مقابل 1.
- شاشة لعب فيها لوحة لودو مرسومة داخل Godot.
- شاشة اللعب مصممة Portrait بحجم لوحة كبير مناسب للهاتف.
- اللوحة داخل `AspectRatioContainer` بنسبة 1:1، والمسارات تعتمد Array من Vector2.
- إطارات اللاعبين تتضمن أفاتار دائري، هدية، كتم، وإطار مضيء لصاحب الدور.
- مؤشرات نبض تظهر على الحركات القانونية.
- مؤقت الدور يستخدم `Timer.timeout` فعليًا مع حلقة نقاط دائرية مرئية.
- دالة `_request_dice_roll()` هي نقطة ربط جاهزة لاحقًا لنتائج Backend عادلة.
- نرد `d6.glb` من `addons/dice_roller` مدمج كتجربة حقيقية أولى.
- 4 قطع لكل لاعب.
- قطع بشكل بيضة/بيضاوي داخل بيوت اللاعبين وعلى السكة.
- لعب ضد 3 لاعبين كمبيوتر.
- خروج القطعة من البيت عند رقم 6.
- مسار لودو رئيسي من 52 خانة.
- حركة القطع خطوة/قفزة مرئية على المسار باتجاه عقارب الساعة.
- مؤقت للرمي والاختيار، وعند التأخير يلعب تلقائيًا.
- خانات آمنة لا يحدث فيها أكل.
- أكل قطع الخصم وإرجاعها إلى البيت.
- طريق نهاية خاص لكل لون مع وصول برقم دقيق.
- فوز عند إدخال كل القطع إلى النهاية.
- زر إعادة مباراة داخل شاشة اللعب.
- تبويب سوق النرد موجود كواجهة، ونرد اللعب الحالي يستخدم أصلًا حقيقيًا من `godot-dice-roller`.
- كاميرا وإضاءة ومنصة عرض وجسيمات.
- سكربت واحد يبني التطبيق داخل المحرك أثناء التشغيل:

```text
scripts/dice_preview.gd
```

## الدمج لاحقًا مع Kotlin

يوجد مشروع Kotlin host جاهز في:

```text
../android-kotlin-host/
```

المسار الإنتاجي:

1. تطوير مشهد النرد/اللعبة في Godot.
2. تطبيق Kotlin يمدد `GodotActivity`.
3. Gradle ينسخ مشروع Godot إلى Android assets أثناء البناء.
4. عند تشغيل التطبيق، Godot يعرض اللوبي والسوق واللعبة.
5. لاحقًا يمكن إضافة Android plugin لتبادل الرسائل بين Kotlin و Godot.
