# Luxury Ludo Dice Preview - Godot

هذا مجلد مشروع **Godot 4** حقيقي للعبة لودو Prototype، وليس صفحة HTML.

## لماذا Godot؟

- محرك ألعاب حقيقي غير Unity.
- مناسب لمشهد نرد 3D، كاميرا، إضاءة، مؤثرات، UI، وتصدير Android لاحقًا.
- يمكن استخدامه لاحقًا كتطبيق/موديول Android بجانب تطبيق Kotlin، أو إعادة بناء المنطق نفسه داخل LibGDX إذا أردت Kotlin بالكامل.

## التشغيل

1. ثبّت Godot 4.x.
2. افتح Godot.
3. اختر **Import**.
4. اختر ملف:

```text
godot-dice-preview/project.godot
```

5. اضغط **Run**.

## التحكم

- اضغط على النرد لرميه.
- أو اضغط زر **ارم النرد**.
- يمكن اختيار شكل النرد من قائمة **سوق النرد**.
- زر Space يرمي النرد أيضًا.

## الموجود في المشروع

- شاشة دخول داخل المحرك.
- شاشة لوبي داخل المحرك.
- شاشة اختيار نمط اللعب مثل 4 لاعبين / 1 مقابل 1.
- شاشة لعب فيها لوحة لودو مرسومة داخل Godot.
- نرد 3D قابل للرمي مع نتيجة واضحة.
- حركة حجر تجريبي على اللوحة بعد نتيجة النرد.
- تبويب سوق نرد داخل المحرك.
- خمسة Skins للنرد مع اختيار وتجهيز.
- كاميرا وإضاءة ومنصة عرض وجسيمات.
- سكربت واحد يبني التطبيق داخل المحرك أثناء التشغيل:

```text
scripts/dice_preview.gd
```

## الدمج لاحقًا مع Kotlin

يوجد مشروع Kotlin host جاهز في:

```text
../android-kotlin-host/
```

المسار الإنتاجي:

1. تطوير مشهد النرد/اللعبة في Godot.
2. تطبيق Kotlin يمدد `GodotActivity`.
3. Gradle ينسخ مشروع Godot إلى Android assets أثناء البناء.
4. عند تشغيل التطبيق، Godot يعرض اللوبي والسوق واللعبة.
5. لاحقًا يمكن إضافة Android plugin لتبادل الرسائل بين Kotlin و Godot.
