# Luxury Ludo Dice Preview - Godot

هذا مجلد مشروع **Godot 4** حقيقي للنردات، وليس صفحة HTML.

## لماذا Godot؟

- محرك ألعاب حقيقي غير Unity.
- مناسب لمشهد نرد 3D، كاميرا، إضاءة، مؤثرات، UI، وتصدير Android لاحقًا.
- يمكن استخدامه لاحقًا كتطبيق/موديول Android بجانب تطبيق Kotlin، أو إعادة بناء المنطق نفسه داخل LibGDX إذا أردت Kotlin بالكامل.

## التشغيل

1. ثبّت Godot 4.x.
2. افتح Godot.
3. اختر **Import**.
4. اختر ملف:

```text
godot-dice-preview/project.godot
```

5. اضغط **Run**.

## التحكم

- اضغط على النرد لرميه.
- أو اضغط زر **ارم النرد**.
- يمكن اختيار شكل النرد من قائمة **سوق النرد**.
- زر Space يرمي النرد أيضًا.

## الموجود في المشروع

- مشهد 3D داخل Godot.
- كاميرا وإضاءة ومنصة عرض.
- خمسة Skins للنرد.
- نقاط مضيئة، جسيمات، هالة ضوئية، ونتيجة نهائية.
- سكربت واحد يبني المشهد أثناء التشغيل:

```text
scripts/dice_preview.gd
```

## الدمج لاحقًا مع Kotlin

أفضل مسار إنتاجي:

1. تطوير مشهد النرد/اللعبة في Godot.
2. تصدير Godot إلى Android.
3. تشغيله كـ Activity أو جزء مستقل بجانب تطبيق Kotlin.
4. تبادل الرسائل بين Kotlin و Godot عبر Android plugin أو واجهة Native.
